Серия — подряд идущие сыгранные матчи лиги (в хронологическом порядке), в которых выполнено условие. Ещё не сыгранные матчи серию не прерывают. «Среднее» — среднее максимальных серий за 5 прошлых сезонов (21-22 … 25-26) без наибольшего и наименьшего значения; «Макс» — наибольшая серия за эти сезоны. Отметка на шкале — 85% от среднего. «Победа фаворита» считается только по матчам, для которых есть коэффициенты К1 / Н / К2 (фаворит — исход с наименьшим коэффициентом).
