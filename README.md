# La Liga 2026/27 — серии

Страница считает текущие и максимальные серии Чемпионата Испании по категориям из вашего Excel-файла
(«К1 не выигр. −1,5», «Обе забьют», «Тотал > 2,5», «Победа фаворита» и др.), сравнивает их со средним
по 5 прошлым сезонам и подсвечивает серии, дошедшие до 85% от среднего.

```
index.html                    страница (читает data/laliga.json)
data/laliga.json              собирается скриптом: календарь, результаты, коэффициенты, история
data/odds.json                накопленные коэффициенты (снимки до начала матчей)
data/history.json             максимальные серии 2021-22 … 2025-26 (считается один раз)
data/manual_odds.json         ваши ручные коэффициенты (необязательно)
scripts/update.py             обновление данных
.github/workflows/update.yml  запуск каждые 3 часа
.github/workflows/backfill.yml разовая загрузка коэффициентов прошлых матчей (платный тариф)
```

## Установка (10 минут)

1. **Ключ The Odds API.** Зарегистрируйтесь на https://the-odds-api.com/ (бесплатный тариф — 500 кредитов в месяц), ключ придёт на почту.
2. **Репозиторий.** На GitHub создайте новый репозиторий (можно публичный) и загрузите в него все файлы из этого архива, включая папку `.github`.
3. **Секрет.** Репозиторий → *Settings → Secrets and variables → Actions → New repository secret*: имя `ODDS_API_KEY`, значение — ваш ключ.
4. **Права Actions.** *Settings → Actions → General → Workflow permissions* → «Read and write permissions».
5. **Первый запуск.** Вкладка *Actions* → «Обновление данных La Liga» → *Run workflow*. Через минуту в `data/` появятся свежие файлы.
6. **Публикация.** *Settings → Pages* → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через пару минут страница будет по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Ключ хранится только в секретах GitHub и в страницу не попадает.

## Как это работает

- **Результаты** — из открытого набора openfootball. Его обновляют волонтёры, поэтому результат может появляться с задержкой.
- **Коэффициенты** — каждые 3 часа скрипт делает один запрос к The Odds API (1 кредит) и сохраняет К1/Н/К2 ближайших матчей — среднее по букмекерам региона `eu`.
  Матч, который уже начался, не перезаписывается: остаётся последний снимок до старта.
  Чтобы брать одного букмекера, задайте переменную `ODDS_BOOKMAKER` (например, `pinnacle`) в шаге запуска в `update.yml`.
- **Прошлые матчи (первые 69).** Бесплатный тариф исторических коэффициентов не даёт. Варианты:
  1. вписать вручную в `data/manual_odds.json`: `{"Barcelona|Getafe": [1.20, 7.00, 13.00]}` (названия — как в таблице «Матчи» на странице, формат «хозяева|гости»);
  2. на платном тарифе один раз запустить workflow «Разовая загрузка исторических коэффициентов» (≈10 кредитов за игровой день).
- **«Победа фаворита»** считается только по матчам, у которых есть коэффициенты; матчи без коэффициентов серию не прерывают.
- Если у API совпадёт не то название команды или матч перенесут дальше чем на 4 дня от даты в календаре, скрипт запишет замечание — оно видно внизу страницы и в логе Actions.

## Локальная проверка

```
export ODDS_API_KEY=ваш_ключ        # можно не задавать — тогда обновятся только результаты
python scripts/update.py
python -m http.server               # и откройте http://localhost:8000
```

GitHub может отключить расписание, если в репозитории долго нет активности; включить обратно можно кнопкой на вкладке Actions.
